# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities through **GitHub Security Advisories**:

https://github.com/vrennat/hn-sidecar/security/advisories/new

This is the preferred reporting channel. If you are unable to use the
advisories form for any reason, open a public issue with minimal detail and
note that it involves a security concern — do not include the vulnerability
details in the public issue.

Reports are reviewed as they are received. No specific response SLA is
guaranteed at this time.
